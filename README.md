# Ikramul portfolio

A responsive React portfolio built with Vite. Run `npm install` and `npm run dev` locally, or deploy to Vercel using the Vite framework preset. `npm run build` creates the production build.

Contact details are intentionally placeholders in `src/main.jsx`; replace them with real email and profile links before publishing. Project visuals are conceptual previews, not screenshots. Confirm each project's technology tags against its actual implementation before publishing.
